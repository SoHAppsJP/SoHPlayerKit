# SoH Player Kit

Shared player components for Cloud Video Player and SoH Media Companion.

## Modules

- `player-core`: Shared player state, models, interfaces, and calculations
- `player-ui`: Shared Jetpack Compose player UI
- `companion-contract`: Communication contract between Cloud Video Player and SoH Media Companion
- `app`: Sample and development application

## Requirements

- Android API 26 or later
- Kotlin
- Jetpack Compose
